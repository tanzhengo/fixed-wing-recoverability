审稿意见回复稿

感谢审稿人对方法定位、实验设计和系统实现提出的具体意见。本次修订将论文的研究对象明确为“有限预算下的终端延续验证调度”，并将候选发现率、端到端计算耗时和闭环任务完成分别评价。几何输入、工作量辅助监督和混合调度均作为可检验的设计选项，不再将三者的必要性作为论文的前提。

本轮保留原始代码、模型及实验记录，新增实现、协议和结果集中保存在 docs/recovery/revision/。原测试集用于失败回放和机制分析；新增32张测试地图用于检验修改后的方法。模型选择和数值前缀检查协议均在访问新测试集之前保存。以下回复按照原审稿意见组织，文中章节名称对应修订稿。

一、关于几何输入、工作量预测和混合调度的实证依据

审稿意见：原稿中的几何输入、工作量预测和Hybrid未兑现主要贡献的论述，且缺少仅BCE与BCE+Huber的受控消融。

回复：我们接受原稿方法定位与消融证据不一致的批评，并进行了以下修改。

1. 新增“输入表示×辅助损失×训练种子”的完整实验。输入为28维State或103维Geometry，辅助损失系数为0或0.1，共采用3个训练种子、12次训练。所有实验使用相同的298,418个训练候选和53,117个验证候选，保留相同训练架构、优化器、训练轮数和批大小；同一种子下配对实验共享初始化与批次顺序。所有模型均依据验证BCE选择检查点，避免使用不可比较的联合损失挑选模型。

验证集结果如下，发现率为三个种子的均值，单位为百分比：

输入/损失                 BCE       K=12发现率    W=3600发现率
Geometry / BCE            0.07645   97.554        87.841
Geometry / BCE+Huber       0.07548   98.183        87.212
State / BCE               0.28208   96.087        86.233
State / BCE+Huber          0.28205   95.947        85.465

这些结果说明，辅助监督的作用取决于预算和输入表示：Geometry的候选数预算发现率提高约0.629个百分点，积分步预算发现率同时下降约0.629个百分点；State的两项发现率均未提高。因此，修订稿不再将工作量辅助损失描述为普遍有效的改进。

2. 移除部署网络中不参与优先级计算的工作量输出。在线优先级明确为可行性概率。Geometry部署网络为103–64–32–1，共8,769个参数；State部署网络为28–64–32–1，共3,969个参数。后者同时省去75个几何探针的计算。这是对既有权重的精确抽取，不涉及再次训练。12个导出模型共768个数值样本的最大绝对logit误差为1.15×10^-5以内；固定部署种子的C++紧凑版与原填充版输出完全一致。

4. 新测试集完整报告四个训练配置及原始冻结模型，避免仅报告最优配置。在共同开启数值前缀检查时，四个新模型的“完成数/边界侵入数”分别为：Geometry+BCE 100/1，Geometry+BCE+Huber 100/0，State+BCE 113/3，State+BCE+Huber 118/0，各含128个回合。工作量辅助损失的验证查询收益与闭环收益并不一致，修订稿分别报告两类结果。Hybrid保留为原实验的消融对象，不再作为部署方法或主要贡献。

二、关于任务代价最小化、净空和后续机动空间的关系

审稿意见：二值延续见证和任务代价最小化可能偏好贴近边界的轨迹，Full-203的局部发现率不能解释其较低的闭环完成率。

回复：修订稿明确区分有限候选集合上的名义任务代价最小化与鲁棒闭环任务目标。Full-203是有限库发现和名义代价的参考，其按代价排序找到第一个可行见证即可停止，并非每次均执行203次延续检查。它也不是任务完成率或最大净空的上界。

为检验审稿人提出的机制，我们精确回放了原Geometry、No-geometry、Diverse和Full的512个回合，结果、控制步数和最终目标距离全部复现。随后从失败回合中提取257个不同的末次规划状态及可执行前驱状态，在相同状态与控制历史下比较各方法。另在128个共同任务上追踪Geometry与No-geometry第一次执行指令分歧，得到124个分歧状态。

在这124个相同状态下，Geometry有99次选择较低任务代价，88次选择较少的可行延续，平均少1.185条/15条。这支持任务进度与后续机动选项之间存在权衡。然而，Geometry的主轨迹最小净空并非普遍更低：42次更低、48次更高、34次相同。因此，修订稿采用实际测量支持的解释，不将所有失败归结为几何网络必然诱导贴边。

我们还对原实验的21次膨胀边界侵入执行完整15条延续检查。对应主轨迹均有3–10条可行延续，未出现仅剩1条的情况。部分延续本身保持较大净空，但即将执行的主轨迹前缀已接近边界。结果表明，主轨迹执行一致性和终端机动选择需要分别分析，增加延续条数本身不能排除前缀越界。诊断所用有符号距离在正方向饱和于30 m，稿件和数据说明均注明这一上限。

本轮修改保留共同的任务代价和延续库，以便隔离调度与数值检查的作用；没有新增净空奖励、风险网络或可行延续比例代价，也未声称已解决鲁棒轨迹优化问题。新增的短前缀检查直接针对所观测到的数值预测不一致，所有基线使用相同规则。该改动与学习排序的收益分别报告。

稿件修改位置：Finite-Library Continuation Feasibility、Short-Prefix Prediction Consistency、Numerical Error and Selection Mechanisms、Discussion。
证据：diagnostics/analysis.json、diagnostics/diagnostic_paired.csv.gz、diagnostics/diagnostic_branchpoints.csv.gz。

三、关于积分步预算与真实计算时间

审稿意见：原学习方法的特征与推理开销抵消了减少延续验证的收益，应提供时间分解并实现实际计算优化。

回复：修订稿不再将延续积分步数直接等同于端到端规划时间。主基元传播、特征提取、推理和调度都计入端到端耗时，延续积分步数仅表示验证预算。

我们实现了两项不改变既定模型选择结果的计算优化。第一，使用上述单输出紧凑网络，State模型不再计算被屏蔽的几何通道。第二，延迟构造学习排序：所有方法先检查共同的最小代价主基元；该候选若存在见证，就已是允许集合中的最低代价选择，无须提取特征和执行网络；若检查失败且预算尚有剩余，则构造与原实现相同的后续序列，继续使用相同剩余预算。这一改动省去容易查询上的固定开销，同时保留需要学习排序时的全部候选。

在576个原匹配状态、两种预算下，Geometry立即/延迟推理、原State填充/紧凑网络以及State立即/延迟推理的六组比较均无决策差异；状态、选择代价、候选次序、见证状态和验证工作量一致。原始重复记录的10,368项比较也通过。这些正确性运行与其他任务同时进行，其计时不作为性能证据。

新计时流程将无埋点端到端计时和分项测量分开。分项包括主基元积分、其余主基元检查、28维标量特征、75维几何特征、网络前向、调度、延续验证和其余开销；新增RK4前缀检查在主基元阶段单独统计，避免重复计入。正式耗时使用固定CPU、轮换方法顺序的重复匹配输入，训练、Gazebo和诊断回放停止后运行。修订稿按这些独立记录报告中位数及尾部耗时，不以积分步减少替代挂钟加速结论。

独立计时已经完成：每个前缀设置包含576个匹配输入、27种方法/预算配置、3次无埋点重复，以及另一次分项遍历。共同开启前缀检查时，同一原State模型的填充版/紧凑立即版/紧凑延迟版平均耗时分别为4.763/4.237/4.134 ms；填充版至紧凑延迟版的中位数由5.005降至3.830 ms，P95由7.487降至6.383 ms，决策及验证工作量一致。

选定State+Aux的中位/P95/平均耗时为3.840/6.362/4.120 ms，Diverse为3.855/5.825/3.853 ms，Full为3.812/13.212/5.059 ms。因此，论文报告其相对Full的均值与尾部优势，以及相对Diverse仍存在的均值/P95开销，不声称全面加速。

Selected的分项平均耗时为：主基元积分2.378 ms、其余主阶段0.234 ms、RK4前缀0.910 ms、标量特征0.00264 ms、几何探针0、MLP 0.253 ms、排序0.019 ms、延续验证0.310 ms、其余0.00963 ms。延迟推理额外省去163/576个输入的网络调用，占全部输入28.30%，或有可行主基元输入的35.21%。47.92%的总无推理比例还包括原本就不推理的无可行主基元输入，未将这部分计为延迟策略收益。

在相同576个输入上，Selected的K=12发现率为415/423（98.11%），Diverse为406/423（95.98%）；W=3600时分别为389/423（91.96%）和312/423（73.76%）。这组近配平输入的前缀检查没有额外拒绝候选，发现率开关前后一致。运行环境为i5-12400F、GCC8.4 -O2、绑定CPU2；频率未锁定，未声称硬实时上界。

稿件修改位置：Feasibility Priority and Deferred Inference、Matched Queries, Closed Loop and Runtime及计算耗时结果表。
证据：runtime/old_state_equivalence.json、runtime/compact_model_parity.json、runtime/PROTOCOL.json；正式计时与分项记录位于runtime下的独立运行文件。

四、关于森林和Gazebo城市实验

审稿意见：森林测试未体现Geometry优势；城市展示未使用传感器地图进行规划，且候选数量和航点容差不同、缺少对照。

回复：我们保留原森林实验的全部结果，包括Geometry在密集地图中的失败。该实验定位为冻结模型的场景转移记录，不再用于支持几何表示优于其他方法。

城市实验的输入链路已在引言和实验部分明确：规划器读取预先提供的建筑碰撞几何，LiDAR点云与体素图用于观测记录和显示。修订稿不使用“基于实时LiDAR地图进行避障规划”或“未知城市环境导航”的表述。本轮没有将点云地图接入碰撞检查与几何探针，也没有新增局部传感器地图闭环。

针对配置差异，新增Cost、Diverse、原Geometry、原No-geometry及选定State+Aux的受控城市比较。五种方法使用同一城市、八个航点、动力学、3 s主时域、6 s延续时域和K=12预算，比较原高度层与加入相对高度层的配置（候选上限分别为203与406）。两组均使用继承的48.825 m水平航点切换阈值；随后在相对高度配置下统一改为15 m，垂直容差均为3 m。

48.825 m来源于继承的前视切换规则(3+0.15)×15.5，而非15 m目标到达精度。修订稿将其称为航点切换阈值，并保留15 m对照。实际目标切换位置和对应水平、垂直误差均有记录。

已完成的15组比较表明：原高度层、48.825 m阈值下，五种方法均未完成第一个航点；相对高度层、48.825 m阈值下，五者均完成循环，结束时刻约90.4–90.8 s；相对高度层、15 m阈值下，仅原Geometry完成循环（114.5 s），Cost、Diverse和所选State+Aux均在完成三个航点后因无可行主基元结束，原No-geometry在完成三个航点后出现膨胀边界侵入。因而原城市演示的完成不能单独归因于学习调度，相对高度候选和航点阈值对结果有明显影响。

城市评价按预先声明的停止条件记录完成、规划失败、膨胀边界侵入及180 s超时。每个配置在同一静态场景中运行一次，结果用于揭示配置影响，不作为跨城市统计结论。闭环验证选出的新模型按同一矩阵完成比较，其选择不使用城市结果；该城市实现与新测试集的RK4前缀消融分开报告。

五、关于积分器差异和侧风

审稿意见：需要检验Euler与RK4差异对边界侵入的影响，并改善数值一致性；忽略风速的长时域预测存在局限。

回复：新增反事实回放固定每次失败前的实际状态和已选控制，仅改变数值积分或执行条件，并以实际0.2 s控制周期为比较时域。在21次历史边界侵入中，Euler 0.02 s检测到0次，Euler 0.005 s检测到15次，名义RK4 0.005 s检测到18次；其余3次只在实际侧风条件下越界。其中Geometry的9次对应为0、8、8和1次。修订稿据此区分数值不一致与扰动效应，不再把全部侵入归因于单一机制。

六、关于有限见证、数据分布和公式细节

1. 有限见证的含义。修订稿将H+B=9 s的延续检验明确为给定控制库中的有限时域后继可行性，不作为递归可行性、控制不变集或无限期盘旋安全性的证明。本文没有新增周期盘旋终端集合或与其对应的实验，相关方法在Related Work和Discussion中与本工作的查询调度问题区分。

2. 数据分布。编码使用相对位移、相对航向及局部坐标中的几何探针，具有共同水平刚体变换不变性，因此不能仅凭绝对位置或绝对航向超出采样区域推断输入分布失配。我们直接对比实际特征：原Geometry闭环所选9,668个候选中，初始航向率超出训练范围的比例为92.67%，初始滚转角为46.30%。训练与验证的初始航向率通道均恒为0，确实存在采样缺口。

为检验其对选择的直接影响，在139个可行失败前驱状态上仅屏蔽Geometry网络中的该输入列，保持真实状态、控制生成器和其他输入不变，选择次序、代价与见证状态均未改变。这一局部检验没有建立其为失败主因的证据。修订稿将范围统计作为分布诊断报告，不将其解释为已证明的因果机制。本轮未扩充训练采样域，以保持输入和损失消融的可比性。

3. 归一化和单位。几何通道明确为clip(d_F(q)/(30 m), -1, 1)，有符号距离在膨胀障碍外为正。所有内部角度与角速度分别采用rad与rad/s，输入的度数在读取时统一转换。我们核对了动力学、升阻力、指令生成与执行模型，没有将角度经验系数按另一种单位重新解释。
